# Tic-Tac-Toe – Python

A classic Tic-Tac-Toe game built using Python and Tkinter, featuring an interactive graphical interface and a computer opponent with selectable difficulty levels.

## Features

- Interactive 3 × 3 game board.
- Human vs Computer gameplay.
- Two difficulty levels: Easy and Hard.
- Easy mode with random computer moves.
- Hard mode with winning and blocking strategies.
- Automatic winner and draw detection.
- Replay option to start a new game.
- Custom dark-themed GUI with contrasting colours.

## Technologies Used

- **Python**
- **Tkinter** – Graphical User Interface
- **Random module** – Random computer moves

## Getting Started

### Prerequisites

- Python 3.x installed on your system.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd tic-tac-toe-game
   ```

3. Run the application:

   ```bash
   python main.py
   ```

## How to Play

1. Launch the application.
2. Choose Easy or Hard difficulty.
3. Click an empty cell to place X.
4. The computer automatically responds with O.
5. The first player to complete a row, column or diagonal wins.
6. Use the Replay button to start a new game.
